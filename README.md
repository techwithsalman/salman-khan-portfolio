# Salman Khan — Cinematic PUBG 3D Interactive Portfolio

A bespoke, immersive, WebGL-powered portfolio engineered for **Salman Khan** — Creative Designer, Full-Stack Web Developer, and AI Automation Specialist based in Karachi, Pakistan.

---

## 🌟 Visual Theme & Atmosphere

- **Cinematic Battleground Aesthetic:** Inspired by high-octane battle royale environments with warm sunset gradients, industrial tactical concrete surfaces, high-contrast hazard hazard bands (`#F5B800`), atmospheric amber/gold reflections (`#FFAA24`, `#FF7800`), and dark graphite containers.
- **Hero Stacking Context & Proportions:**
  - Background: Atmospheric Battleground with radial warmth.
  - Layer 1: Oversized `SALMAN KHAN` SVG wordmark typography with subtle depth shading.
  - Layer 2: Decorative `design & code` script typography positioned safely leftward to preserve facial clarity.
  - Layer 3: PUBG Survivor character featuring level-3 tactical gear, laptop, telecommunication headset, and companion bot. Proportionally scaled to provide generous vertical headroom.
  - Layer 4: Interactive, hanging PUBG ID badge card with textured yellow lanyard, realistic suspension physics, and Salman's verified credentials.
- **Laptop Showcase Diving Experience:** Smooth scroll pinning that seamlessly guides visitors through Salman's 8 flagship web and AI software projects.
- **3D Curved Exhibition Gallery:** Full Three.js WebGL curved corridor featuring tactical concrete walls, safety warning stripes, supply crate decals, warm amber road reflections, and interactive poster viewports.
- **Dedicated Battleground CV Section:** Integrated download hub featuring Salman's full career credentials, technology stacks, education, and direct contact avenues.
- **Retro CRT Closing Scene (`SK//TV · CH 02`):** Masked retro CRT monitor embedded in a golden-hour battleground landscape, streaming actual production recordings of Salman's web applications.
- **Tactical Footer:** Single-line branding: `CREATIVE DESIGNER, DEVELOPER & AI AUTOMATION BUILDER — KARACHI, PAKISTAN.` with copyright notice `© 2026 SALMAN KHAN | TECH WITH SALMAN`.

## 🛠️ Technology Stack

- **Graphics & 3D:** Three.js, WebGL, Canvas Confetti
- **Animation & Scrolling:** GSAP (GreenSock), ScrollTrigger, Lenis Smooth Scroll
- **Styling:** Custom Tactical CSS, Tailwind CSS tokens
- **Architecture:** Client-side hydrated static bundle with zero external vendor tracker overhead.

## 📦 Project Setup

```bash
# Install dependencies
npm install

# Start local preview server
npx serve -l 8080 -C -S .
```

Open `http://localhost:8080` in any modern web browser (Edge, Chrome, Safari, Firefox).
